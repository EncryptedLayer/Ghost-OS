# Ghost OS

**The AI command layer for crypto.** Say what you want onchain, in English or your own language, and Ghost OS turns it into real onchain actions you review and approve.

A flagship product by [Encrypted Layer](https://encryptedlayer.org).

**Launch the app:** https://ghostos.network

## What Ghost OS does

- **Swap, bridge and send** across supported chains from one chat box
- **One command, up to five transactions**: bridge, buy and send in a single plan you review once
- **Token scanner**: honeypot, tax, liquidity and contract checks in one sentence
- **Launchpad**: launch a token with 100% of supply as liquidity, locked forever, in one signature (in final security testing)
- **Portfolio and activity** across chains, with real transaction hashes only
- **Two wallet modes**: Ghost Wallet for instant execution, or your own external wallet approving every transaction
- **Multilingual commands**: English, Spanish, Chinese, Japanese, French, Portuguese, Hindi, Arabic and more

## Safety by design

- Ghost OS never asks for your seed phrase
- Every action is shown before anything is signed
- Only real transaction hashes are reported, never simulated results
- AI output is validated before it can reach a wallet action

Details: [Security model](https://ghostos.network/docs/security)
